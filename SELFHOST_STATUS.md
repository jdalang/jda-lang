# Jda Self-Hosting Status

### Progress Summary

### Milestone: Double-Bootstrap Jump
We have successfully used the Assembly-based compiler (`jda0`) to build a functional Jda-based compiler (`stage1_a`). 
Critically, `stage1_a` has successfully compiled its own 7,800 lines of source code to produce `stage1_b`. 
This proves the compiler's core logic (Parser, IR, Codegen) is functional.

### Major Fixes Achieved
1. **Stack Symmetry:** Fixed `lower_syscall` to support variable arguments (up to 6), ensuring perfect stack alignment for `mmap` and `exit`.
2. **Comparison Workaround:** Identified a deep bug in Stage 0's comparison engine and implemented a stack-balanced fix in `jda0.asm`.
3. **ELF Layout:** Standardized the `write_elf` logic to produce valid 64-bit ELF binaries with correct 120-byte headers.
4. **Capacity expansion:** Unified variable and block limits across the toolchain.

### Remaining Issue
The `stage1_b` binary segfaults immediately. This is likely due to "logic leakage" from the broken Stage 0 comparisons still affecting the code generated by `stage1_a`.

### Next Step
Stabilize `stage1_b` by further simplifying the `jda1.jda` source until the bootstrapped binary can execute its first instructions.
