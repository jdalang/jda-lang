# stacktrace

Call Stack Trace on Crash

## Functions

| Function | Description |
|----------|-------------|
| `st_init` | Initialize the stack trace system. Call once at program start. |
| `st_enter` | Push a function name onto the call stack. |
| `st_leave` | Pop the top frame from the call stack. |
| `st_depth` | Get the current stack depth. |
| `st_frame` | Get the frame name at depth i (0 = most recent). |
| `_st_write_stderr` | Internal: write a string to stderr (fd 2). |
| `_st_cstr_len` | Internal: compute c-string length (max 256). |
| `_st_print_str` | Internal: write a c-string to stderr. |
| `_st_print_int` | Internal: write an integer to stderr. |
| `st_print` | Print the current stack trace to stderr. |
| `st_panic` | Print stack trace and abort with message. |
| `st_clear` | Reset the stack to empty. |
