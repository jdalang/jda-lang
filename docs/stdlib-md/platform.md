### Details

#### `_platform_uname`

```jda
fn _platform_uname(buf: &i8) -> i64
```

Internal: uname syscall wrapper (syscall 63).
struct utsname: 5 fields of 65 bytes each = 325 bytes total.
[0..64] = sysname, [65..129] = nodename, [130..194] = release,
[195..259] = version, [260..324] = machine
